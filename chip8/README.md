# CHIP-8 Emulator

This external application is a modern Momentum Firmware port of the CHIP-8
implementation from `v1nc/flipperzero-firmware` at commit
`bc7e846c9a7c1f23a4eabc786581fbc8c1700bff`.

The original repository is licensed under GPL-3.0. The bundled `LICENSE` is
preserved here. The port updates the application manifest, Furi strings, file
browser integration, and resource cleanup for the current Momentum API.

Place `.ch8` ROM files in `/ext/chip8` on the SD card.
